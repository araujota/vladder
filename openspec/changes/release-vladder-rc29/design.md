# Design

The release artifact is a package resource loaded through `importlib.resources` and validated by
the public schema registry. CI installs the built wheel before reading it, so package-data omissions
fail publication.

Composition-native traces remain the frontier-native source of future policy supervision. The
emitter derives one readiness contract from trace contents and rejects any mismatch. Integrity
checks cover canonical owner uniqueness, parent lineage, sibling cardinality, generated children,
selected-action membership, label/oracle permutations, terminal ownership, summary counts, and
content hash. `inference_view` projects only pre-decision context.

The general v3 bundle remains compatible auxiliary supervision. Exact reductions, proof,
compilation, and physical evidence retain their established authority.
