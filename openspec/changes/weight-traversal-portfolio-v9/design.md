# Design: Weight-Reuse Portfolio Measurement V9

The portfolio weights interactive, prompt, concurrent, and KV pressure at 30/20/35/15 percent.
Default batched execution and a sequence-separated `-tgs` diagnostic establish the causal value
of ready-lane reuse. Model file bytes are only a reproducible logical proxy for streamed weights;
external DRAM bytes are not claimed. Randomized fresh-process identity controls remain raw data,
but effective ranking is an exact tie after deduplication. A portfolio average cannot override
the one-percent interactive floor or novelty requirement.
