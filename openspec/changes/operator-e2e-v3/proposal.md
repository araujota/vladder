# Change: Operator Synthesis E2E V3

## Why

Independent component tests do not demonstrate that contracts, graphs, search,
proof, compilation, measurement, ranking, integration, and patch emission form
one reproducible system.

## What Changes

- Add the requested `operator optimize` and `pipeline optimize` CLI surfaces.
- Add full candidate audit/report language and mixed-configuration refusal.
- Run paired token and HFT demonstrations with graph-level winners.
- Track system and domain acceptance independently from implementation completion.

## Success

All artifacts are reproducible from manifests; no unverified candidate wins;
reports use bounded-optimality language; and domain criteria remain explicitly
open when production/model or statistical evidence is absent.
