# Public Roadmap

## Release Gate

- Stable schema registry and compatibility tests.
- Clean Ubuntu installer and container smoke coverage.
- Canonical agent-review records and optional review service.
- Public technical site with release downloads.
- Seeded semantic/security CI and documented scanner setup.

## Near Term

- Broaden executable C++ proof units without pretending to support arbitrary ownership protocols.
- Add architecture-calibrated GPU source lowerers beyond launch/workgroup geometry.
- Add incremental lifetime identity tracing and invalidation coverage.
- Expand common dataflow emitters across supported systems-language frontends.

## Good First Issues

1. Add a rejected schema fixture for each stable artifact kind.
2. Add a small C stencil demo with a complete claim-boundary table.
3. Improve `vladder schema validate` error hints for nested arrays.
4. Add AMD and Intel example GPU architecture manifests with cited field provenance.
5. Add benchmark-manifest examples for fixed-frequency and boost-regressed modes.
6. Document one real negative optimization result from an open-source project.
7. Add a new grammar rule only after supplying attribution, good/bad seeds, and a lowerer test.

Issues should be labeled `good first issue`, `documentation`, `grammar`, `proof`, `benchmark`, or
`frontend`. A roadmap item is not a capability claim until its tests and proof boundary ship.
