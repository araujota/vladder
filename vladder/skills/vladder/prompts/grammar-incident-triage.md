# Grammar Incident Triage Prompt

Given a vLadder inspection or audit directory, classify every stopped region without changing the
target repository.

1. Read the promotion summary, `region-closure.json`, compiled effects, semantic graph, and proof
   envelope.
2. Classify the stop as `local_grammar_gap`, `finite_protocol_contract_required`,
   `application_runner_required`, or `physically_external`.
3. For SPIR-V, separate opcode capture from unresolved numeric, validity, descriptor, capability,
   output-oracle, and timestamp obligations.
4. For structured C++, report recognized archetypes and `structured_lowering_route`; do not call a
   plan an executable candidate.
5. For recursive calls, distinguish definition-visible transitive effects from actual external or
   indirect calls.
6. Propose the smallest bounded next action and list the observable state, failure, cleanup,
   publication, and retirement channels it must preserve.
7. State which neighboring closed regions remain optimizable even when the owning wrapper is not.

Return one table with: region, measured attribution, closure class, executable status, unresolved
obligations, next command/adapter, and prohibited claim.
